# Статистика

Только заготовки с комментариями, без исполняемого кода и подключения к игре.

- `player/death.mcfunction` — число смертей игрока.
- `player/kill.mcfunction` — число убитых игроком сущностей.
- `player/placed.mcfunction` — количество поставленных объектов, общее и отдельно по типам: блоки, ловушки и т. д.
- `spawn/enemy.mcfunction` — общее количество появившихся врагов.
- `spawn/resistance.mcfunction` — количество врагов с каждым сопротивлением для расчета процента выпадения.

Личные показатели привязывать к постоянному ID игрока. Сохранять накопленные значения между матчами и не очищать при /reload.

Для сопротивлений хранить количества, а процент получать из них при просмотре. При отсутствии спавнов показывать «нет данных». Например, 20 врагов с определенным сопротивлением из 100 появившихся — 20%. Это наблюдаемая частота, которая на небольшой выборке может отличаться от настроенного шанса. Врагов без сопротивлений тоже учитывать. Если возможны несколько сопротивлений одновременно, сумма долей по типам может превышать 100%.
